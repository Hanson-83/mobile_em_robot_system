## 1. 范围与边界

### 1.1 In Scope（范围内）

- 基于标准 AMR 改装的移动环境监测机器人（含导航、避障、充电、电梯跨层能力诉求）。
- MVP 监测仪表：便携式粒子计数器、在线温湿度仪、在线风速仪及采样头/探头。
- 上位机（服务器 + 多类型客户端）：任务编排调度、数据采集与可视化、报警事件、批报告、权限、可开关审计/电子签名、备份恢复、设备适配层、对外 API。
- 单上位机节点对多台机器人的集群调度。
- 洁净室/无尘室场景下的环境监测与数据采集（半导体、制药 GMP、生命科学、新能源、医疗等相关设施）。

### 1.2 Out of Scope（范围外）

- 地面吸尘、拖地等清洁功能（他厂方案含清洁模块；**本系统不做清洁机**）。
- 正式合规认证/证书出具（如完整 IQ/OQ/PQ 包、第三方 Part 11 认证）— 本 URS 仅要求**取向与可开关能力**，认证范围 TBD。
- 具体厂商仪器/AMR 的最终商务选型结论（本文仅提能力需求；选型见技术方案，未定项标 TBD）。
- 厂房土建、电梯硬件改造本身（依赖现场与供应商协作，标 TBD）。

### 1.3 分期

| 阶段 | 内容 |
|------|------|
| MVP | 粒子 + 温湿度 + 风速；单/多机基础调度；地图可视化；报警；批报告；权限；适配层骨架；WiFi；充电桩 |
| 扩展 | 浮游菌采集器及其他环境监测仪表；更丰富编排与看板 |
| 远期 | 协作臂（优先国产 6/7 轴）+ 末端深度相机；采样头上臂的定点/轨迹采样 |

## 2. 干系人与使用场景

| 角色 | 典型诉求 |
|------|----------|
| 洁净室/QA 运营 | 按计划自动巡检，数据可追溯，报警及时 |
| 设施/EHS | 温湿度、风速、粒子超限告警与趋势 |
| 制药验证/合规（如适用） | 审计追踪、电子签名可开关，数据完整性取向 |
| 系统集成/运维 | 适配多品牌设备、备份恢复、日志可观测 |
| 开发/测试 | Fake/Simulator、OpenAPI、分层测试 |
| 管理层 | 多机效率、批报告、看板 |

**主场景（MVP）**：运营在上位机编排「区域 A→B→C」监测任务 → 机器人导航至点位 → 触发仪表采样 → 数据上传与可视化 → 超限报警 → 任务结束生成批报告。

**扩展场景**：浮游菌采样任务；断网缓存后续传。

**远期场景**：机械臂将采样头移至固定高度/轨迹采样。

## 3. 术语

| 术语 | 说明 |
|------|------|
| AMR | Autonomous Mobile Robot，自主移动机器人 |
| 上位机 | 中央编排调度与数据中控软件（服务器 + 客户端） |
| 原子技能 | 不可再分的可执行动作（如导航到点、开始粒子采样） |
| 任务 | 由一组原子技能组成的可调度单元 |
| 组合任务 | 由多个任务按顺序/条件组成的工作流 |
| 集群任务 | 多机器人协同或并行的任务编排 |
| 适配层/网关 | 隔离业务与具体设备协议的驱动适配框架 |
| Fake/Simulator | 无硬件环境下的设备模拟实现 |
| Part 11 | 21 CFR Part 11，电子记录与电子签名相关法规取向（本系统为可开关能力，非已获证声明） |
| TBD | 待确认 |

| URS-ROB-004 | 提供 AMR 可编程/可调用 API（导航、状态、充电等） | Must | 有文档化 API；适配层可完成连接、心跳、导航到点、状态订阅 | MVP |
| URS-ROB-005 | 车载无线（路由器/网卡）接入现场 WiFi，与上位机通信 | Must | 在约定覆盖区内可维持任务遥测与指令通道；断线策略见 URS-COM | MVP |
| URS-ROB-006 | 电池与仪表供电插座/配电满足改装仪表功耗（功率清单 TBD） | Must | 仪表在任务全程供电稳定；急停/断电策略文档化 | MVP |
| URS-ROB-007 | 支持电梯交互，进出电梯实现跨楼层移动 | Should | 与电梯厂商/楼控协议联调通过，可完成至少一层跨层往返（现场依赖 TBD） | MVP |
| URS-ROB-008 | 洁净室材质与表面处理满足目标洁净等级（等级 TBD） | Should | 材料清单与清洁维护规程获现场确认 | MVP |
| URS-ROB-009 | 安全防护：急停、触边/激光避障等（具体传感器配置 TBD） | Must | 急停可立即停机；避障在验收场景下不发生不可接受碰撞 | MVP |

### 4.2 监测仪表

| ID | 描述 | 优先级 | 验收标准 | 阶段 |
|----|------|--------|----------|------|
| URS-INS-001 | 集成便携式粒子计数器及采样头，可远程启停与读数 | Must | 适配层可启动/停止采样并读取粒径通道数据；数据带时间戳与点位 ID | MVP |
| URS-INS-002 | 集成在线温湿度仪及探头，可连续或点位读数 | Must | 温度、湿度数值正确写入时序库；单位与精度在配置中声明 | MVP |
| URS-INS-003 | 集成在线风速仪，可对监测点（如 HEPA/FFU 相关点）读数 | Must | 风速数据可读；采样高度/姿态依赖机械方案 TBD | MVP |
| URS-INS-004 | 仪表通信经适配层，协议细节不泄漏到业务编排 | Must | 业务仅调用领域命令；协议（如 RS485/Modbus 等）仅存适配层与配置 | MVP |
| URS-INS-005 | 仪表型号可配置替换（YAML），新增型号以适配器+配置为主 | Must | 切换 Fake 与至少一种真实/录制回放适配器无需改编排核心代码 | MVP |
| URS-INS-006 | 集成便携式浮游菌采集器（模块+采集头） | Should | 可下发采样时长/流量等参数（以选型为准 TBD）并记录任务关联数据 | 扩展 |
| URS-INS-007 | 仪表计量校准状态可登记（校准到期提醒可选） | Could | 可录入校准日期/证书编号；到期提醒可配置 | 扩展 |

## 6. 假设与依赖

1. 现场提供满足覆盖与隔离要求的 WiFi/VLAN（具体指标与他厂清单对齐时需现场复测，**不直接照搬为承诺**）。
2. AMR 厂商提供可用 API 与电梯联动方案或配合二开。
3. 仪表厂商提供通讯协议文档与供电规格。
4.  elevators / 楼控方允许对接（协议与责任边界 TBD）。
5. MVP 可不启用审计/电子签名即可完成主流程验收；制药客户试点再打开开关并补流程。

## 7. 开放问题（需用户确认）

1. 目标洁净等级与适用行业首站（半导体 / 制药 / 其他）？
2. AMR 候选厂商短名单与是否已有商务接触？
3. 粒子/温湿度/风速最终型号与通讯方式？

6. 多机路径冲突与交通管制策略期望？
7. 批报告格式与是否需电子签名批准流？
8. 对外 API 首批对接的第三方系统是什么？
