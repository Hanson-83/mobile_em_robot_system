## 3. 符合项

- **状态机（DS §6.1）**：`task_fsm.py` 定义迁移表与 `TERMINAL`；`Scheduler._transition` 统一经 `assert_transition`；`start`/`stop` 对终态拒绝；`recover_interrupted` 将 `Running`/`Dispatched` 迁为 `Failed`（`PROCESS_LOST`），不触碰已终态任务；单测 `test_fsm_rejects_terminal_restart` 覆盖终态不可重启。
- **默认排队（用户确认 + scheme §5.1）**：`FeaturesConfig.on_conflict` 默认 `queue`；`MutexService.try_acquire` 冲突返回 `None`；调度在 `Queued` 保留并写 `queue_reason`；`test_queue_then_start` 证明释放锁后 `/start` 可完成，**非直接失败**。
- **锁获取顺序（调度侧子集）**：`_try_run` 先 `elevator` 再 `point`，与 scheme 固定序 **zone → elevator → charger → point** 中已建模类型的相对顺序一致；冲突时释放已持有的嵌套锁（`_release_held`）。
- **电梯独立（DS §6.3 / decisions）**：电梯在 `registry.elevators` + `ElevatorFake`，`AmrFake` 无电梯技能；任务经 `scheduler._execute` 调用 `call/enter/exit`；`test_smoke_task` 断言 `elevator_trace` 与门/楼层状态。
- **断线默认重连（decisions + DS §8）**：`session_on_disconnect=reconnect`，`reconnect_attempts=3`（`features.example.yaml` 一致）；`Scheduler._call` 对 `DEVICE_OFFLINE` 重试并在用尽后失败；覆盖成功重连与 `link_down` 终败用例。
- **仪表与 Modbus 占位**：粒子 `0.1/0.5/1.0/5.0µm`、`count/cf`；温湿度 ℃/%（寄存器 ×10）；风速 m/s（×100）；`ModbusHoldingSim` 占位读写。
- **报警与报告可测**：超限写 `store` 报警、`POST /alarms/{id}/ack`、`POST /reports` + `GET /reports/{id}/file`；M2 集成测 `test_exceed_alarm_ack_and_report`。
- **持久化**：`Store` SQLite 任务/测量/报警/报告；测量 `INSERT OR IGNORE` 幂等键。
- **地图**：`POST /api/v1/maps/import` GeoJSON Point；`test_geojson_import`。
- **安全基线（相对 M1）**：口令经环境 `MER_DEV_USERS_JSON` 注入；`test_placeholder_secret_rejected`；`misc` 路由使用 `import app.main_state as state` 读取 live `features`（M1-C07 类问题已避免）。
