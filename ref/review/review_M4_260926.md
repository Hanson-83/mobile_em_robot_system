## 4. 重点核对（审核关注点）

| 关注点 | 结论 | 证据 |
|--------|------|------|
| 未登录能否进业务页 | **否（路由层）** | `router.beforeEach`：`to.path !== "/login" && !getToken()` → `/login`（`router/index.ts` L31–34） |
| 签名开启时限值是否提示批准 | **部分** | 页眉文案「开启（改限值走批准流）」；保存遇 `APPROVAL_REQUIRED` 时 `notice` 含 `approval_id`（`PointsView.vue` L68–69）；**无跳转/链至批准中心**，且仍写入 `error` 红字，易与失败混淆 |
| 报告是否仍要求手抄易错 ID | **否** | `ReportsView` 用任务 **`<select>`** 绑定 `taskId`，默认取列表首项（L61–67） |
| 密钥是否写进前端源码 | **否** | 见 §2；Login 文案提醒勿提交口令 |
| 页面是否有死链 | **未发现** | `App.vue` 九条 `RouterLink` 与路由表一致；无外链 404 |
| 仅调 Gateway | **是（HTTP）** | 全部经 `/api/v1/*`；报告文件下载同源 `fetch` |

补充说明（非 P0，但影响体验与安全纵深）：

- **门禁仅校验 token 是否存在**，不校验过期；API 401 时 **无全局清 token / 重定向**（`api/client.ts`）。
- **登录页仍渲染顶栏九项业务导航**（`App.vue` 未按路由隐藏）；未登录点击会回到 `/login`，**不是死链**，但易误解为「未登录可见菜单」。
- plan WBS-6 写明 **WebSocket 实时通道**；前端 **未建立 WS 连接**（`TrendsView` L42 占位说明）。
