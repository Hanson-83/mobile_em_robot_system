## 3. 符合项

- 仓库目录符合 `project_scheme.md` §4.2：适配层位于 `backend/app/adapters/`，不存在顶层独立 `adapters/`。
- `AmrAdapter`、`AmrFake` **未包含** `call_elevator` / `enter_elevator` / `exit_elevator`；电梯方法仅位于独立 `ElevatorAdapter` / `ElevatorFake`，任务冒烟也通过独立电梯注册表调用。
- `ElevatorFake` 提供 Call / Enter / Exit、楼层检查及失败注入；当前功能可执行，但测试强度仍有缺口，见 M1-C04。
- 仪表配置默认 `access_mode: direct`，工厂会拒绝 `via_edge_agent`；符合 MVP 直连约束。
- 厂商适配器明确命名为 `VendorStub`，连接时返回 `NOT_IMPLEMENTED`，健康状态含 `stub: true`，没有伪装成已联调。
- `features.example.yaml`、`devices.example.yaml` 及 `FeaturesConfig` 默认均为 `e_sign=false`。
- 同步任务冒烟仅保存终态并明确注明“完整状态机属 M2”，未实现 Created→Queued→Dispatched→Running 等完整 M2 状态机，**未发现范围膨胀**。
- Vue 使用 TypeScript 严格模式，登录、地图、任务三个页面壳均通过构建。
- `.env`、虚拟环境、依赖目录和构建产物已有忽略规则。

## 6. 优先整改

1. **先关闭 P0**：移除有效默认凭据/固定签名密钥，统一 HTTP 与 WebSocket 错误体，并把错误契约纳入自动化测试。
2. 补齐 OpenAPI 最小资源草图及错误 schema，避免静态草图与运行时 schema 双轨漂移。
