## 4. 重点核对（审核关注点）

| 关注点 | 结论 | 证据 |
|--------|------|------|
| stable ↔ runtime 路径集合 | **部分漂移** | runtime only：`/admin/backup`、`/admin/restore`、`/approvals/{approval_id}/decide`、`/trends`、`/reports/{report_id}/file`、`/robots/{robot_id}/navigate`、`/audit/{event_id}` 等；stable only：`/backup`、`/restore`、`/approvals/{id}/decide`、`/ws` |
| `/api/v1/backup`（stable） | **不可用** | 实测 POST → **404 `NOT_FOUND`**；实际为 `POST /api/v1/admin/backup`（200） |
| MES 与 Web 双实现 | **调度层共用，响应略异** | 均调 `scheduler`/`store`；`/realtime` 无 `tasks`，MES realtime **含 `tasks`**（文档写「共用存储」未声明字段差） |
| `client_request_id` | **仅回写，非幂等** | 同 id 两次 POST 得到**不同** task id（实测） |
| WebSocket 服务账号 | **不支持** | `misc.ws_gateway` 仅 `parse_token`，不走 `resolve_bearer`；M5 首批以 HTTP realtime 为主 |
| 密钥入库 | **未发现** | Token 环境注入；`hash_token_hint` 未把明文写入 store |
