## 1. 目标与里程碑

### 1.1 目标

交付可试点的 MVP：改装 AMR 搭载粒子/温湿度/风速，上位机完成多机可扩展的任务编排、数据采集可视化、报警、批报告、权限与可开关审计/签名，设备经适配层接入，具备 Fake 与真机联调路径。

### 1.2 里程碑（日期待排期，状态为规划）

| ID | 里程碑 | 完成标志 |

## 4. 任务优先级与依赖

```text
选型(1) ──┬─→ 改装(3) ──→ 边端(4) ──┐
          │                        ├─→ 联调(6) → 测试(7) → 试点(8)
URS评审(2)─┴─→ 上位机MVP(5) ─────────┘
                 ↑
            Fake 可并行先于真机
```

优先级：

1. **P0**：适配层 + Fake 全链路、任务状态机、点位与时序存储、鉴权。
2. **P0**：真机 AMR 导航适配、粒子/温湿度/风速适配。
3. **P1**：报警、批报告、地图可视化、断点续传。
4. **P1**：审计/签名开关、备份恢复、对外 API。
5. **P2**：多机集群策略增强、电梯、桌面/移动端。
6. **P3**：浮游菌、臂与深度相机。

## 6. 测试方案

对齐 `spec/testing_quality.md` 分层；保护行为而非实现细节。

### 6.1 分层策略

| 层级 | 范围 | 工具/方式 | CI |
|------|------|-----------|-----|
| 单元 | 解析、限值判断、状态机转换、协议编解码 | pytest | 默认跑 |
| 集成 | API + 仓储；网关 + **Fake 设备** | pytest + TestClient | 默认跑 |
| 端到端 / 冒烟 | 启动 → 下发任务 → Fake 完成 → 报告/报警 | 脚本/compose | 关键冒烟 |
| 仿真 | 多机调度冲突、断网续传 | Fake 时钟/网络注入 | 夜间可选 |
| 硬件在环 HIL | 真机导航、真仪表采样 | 现场/实验室 | **标记跳过默认 CI** |
| 验收 | URS ID 用例 | 验收记录表 | 试点前 |

### 6.2 Fake / Simulator 要求（Must）

- `AmrFake`：模拟导航耗时、电量、故障注入。
- `ParticleFake` / `ClimateFake` / `AirflowFake`：返回可配置曲线与超限值。
- 配置切换真实适配器不改业务代码（URS-ADP / URS-INS）。

## 7. 风险与缓解

| 风险 | 影响 | 缓解 |
|------|------|------|
| AMR API/电梯能力不足 | 跨层或调度延期 | 早期 PoC；MVP 可单层豁免 |
| 仪表无通讯或协议封闭 | 集成失败 | 选型必含通讯样例联调 |
| 风速高点机构复杂 | 成本/进度 | MVP 先做低点；高点单列 |
| WiFi 质量差 | 丢控/丢数 | 专用 VLAN；强依赖断点续传 |
| 洁净室准入与材质 | 无法进场 | 提前材料清单评审 |
| 范围蔓延（清洁/臂） | 资源被抽走 | 严格分期；臂走远期预研 |
| 合规期望过高 | 认证范围爆炸 | 明确「取向+开关」非证书 |
