## 1. 总体方案与分期

### 1.1 定位

构建「**AMR 改装 + 上位机自研**」的移动环境监测系统：机器人到点采样，上位机编排调度、数据中控与看板。应用于洁净室/无尘室（半导体、制药、生命科学、新能源、医疗等）。

**明确不做**：吸尘/拖地等清洁功能（他厂方案含清洁模块，仅作对照，非本系统范围）。

### 1.2 分期

| 阶段 | 硬件 | 软件 |
|------|------|------|
| MVP | AMR + 粒子 + 温湿度 + 风速 + 充电桩 + WiFi + 电梯联动诉求 | 适配网关、调度、数据看板、报警、批报告、RBAC、审计/签名开关、备份、OpenAPI、Fake |
| 扩展 | 浮游菌及其他仪表 | 更丰富编排、桌面/移动客户端增强 |
| 远期 | 国产协作臂 + 深度相机，采样头上臂 | 臂技能、轨迹采样、视觉辅助 |

### 1.3 架构一句话

单体模块化上位机（FastAPI + TS 前端）经**设备适配网关**连接多品牌 AMR/仪表；边端负责本地采集缓存与断点续传；配置 YAML；合规能力可开关。

## 2. AMR 选型与改装要求清单

### 2.1 选型原则（厂商未定，标 TBD）

- 开放或文档完善的 **API**（导航到点、取消、状态、充电、地图/点位）。
- 支持或可合作 **改装**：仪表仓、供电、走线、采样头外伸/高度。
- SLAM、避障、自动充电成熟。
- **电梯联动**能力或二开接口。
- 洁净室友好材质/密封与维护便利性。
- 国内服务与备件响应（权重 TBD）。

### 2.2 MVP 改装清单

| 项 | 要求 | 状态 |
|----|------|------|
| 便携式粒子计数器 + 采样头 | 安装固定、进气口无遮挡、振动影响评估 | TBD 型号 |
| 在线温湿度仪 + 探头 | 探头位置代表环境空气 | TBD |
| 在线风速仪 | 高度可能显著高于车体（他厂参考 HEPA ~250 cm） | 机械方案 TBD |
| 车载无线 | 路由器/网卡，接入现场 WiFi | |
| 电池与仪表供电 | 独立保险/开关；功率预算表 | TBD |
| AMR API | 供适配层对接 | 必选 |
| 充电桩 | 自动回充 | |
| 电梯交互 | 呼叫/乘梯/出入逻辑 | 依赖现场 |
| 急停与安全传感 | 符合现场安全评审 | |

### 2.3 扩展 / 远期预留

- 浮游菌采集器仓位与培养皿操作流程（人工取皿 vs 自动 — TBD）。
- 臂基座接口、载荷、电缆拖链、深度相机安装。

### 2.4 参数量级参考（参考他厂，非本系统选型结论）

派特纳评估方案中整机示例量级（清洁+监测一体机，**与本系统形态不同**）：外形约 670×550×880 mm；速度 0–1 m/s；最小过道约 900 mm；电池 DC24V 60AH 量级；监测续航约 8 h（其场景）。本系统以所选 AMR 规格书为准，**不得将上述数字直接写入招标承诺**。

## 3. 监测仪器集成方案

### 3.1 原则

- 通讯与供电进入 **适配层 + YAML**；业务只发领域命令。
- 每种仪表：真实适配器 + Fake；协议文档归档 `ref/` 或供应商包（注意保密）。
- 计量校准周期由运营管理；系统可登记证书信息（Should）。

### 3.2 通讯要点（参考他厂，非选型结论）

| 仪表 | 他厂示例 | 通讯提示 | 本系统 |
|------|----------|----------|--------|
| 粒子 | 加野 3720-6 量级 | RS485、Modbus；流量约 28.3 L/min；多粒径通道；响应约 60 s 量级 | 型号 TBD |
| 温湿度 | 力夫 LFH103 量级 | 需确认通讯能力；他厂曾排除无通讯型号 | 型号 TBD |
| 风速 | （他厂提及客户推荐无通讯不可用） | 必须可选带通讯型号 | 型号 TBD |
| 浮游菌 | — | 启停、时长、流量、状态 | 扩展 TBD |

### 3.3 采样与点位

- 点位绑定仪表 profile 与限值。
- 粒子采样需考虑稳定时间（他厂时间评估中单点落尘+温湿度约 70 s 检测量级，**仅参考**）。
- 超限复测策略可作为组合任务模板配置。

### 3.4 高度与机构

- 落尘/温湿度：他厂参考约 80–115 cm。
- HEPA 风速：约 250 cm — 可能需要升降杆或远期机械臂；MVP 是否覆盖高点 **TBD**。

## 4. 上位机软件方案

### 4.1 模块

见 `doc/spec/ds.md`：API、调度、数据、报警、报表、鉴权、适配网关、审计/签名、备份、前端。

### 4.2 建议目录（单体仓库）

```text
mobile_em_robot_system/
  backend/
    app/
      api/           # 路由
      domain/        # 任务、点位、报警等领域
      adapters/      # AMR/仪表/仓储实现
      services/      # 调度、报表、备份
      core/          # 配置、安全、错误模型
    tests/
    pyproject.toml   # uv
  frontend/
    src/
  config/
    devices.example.yaml
    features.example.yaml
  doc/
  ref/
  spec/              # 或沿用仓库已有 spec
  deploy/
    docker-compose.yml
```

### 4.3 适配网关

- `AdapterFactory` 按 `type` 装配。
- 统一生命周期：`start/stop/health`。
- 遥测归一化为领域 DTO。
- 集成测试：网关 + Fake 设备。

### 4.4 配置示例（示意）

```yaml
# config/devices.example.yaml
robots:
  - id: robot-01
    adapter: amr_fake   # 或 amr_vendor_x
    endpoint: "http://192.168.x.x/api"
instruments:
  - id: pc-01
    robot_id: robot-01
    adapter: particle_fake
    # port: /dev/ttyUSB0
    # baudrate: 9600
features:
  audit_trail: false
  e_sign: false
```

## 5. 地图 / 点位 / 调度

1. **建图**：现场用 AMR 厂工具 SLAM；地图导入或同步到上位机显示层。
2. **点位**：在地图上标注监测点；导出/导入 JSON/YAML；与任务引用。
3. **调度**：
   - MVP：单机队列 + 多机简单并行（资源锁：点位/电梯/充电桩）。
   - 冲突：先互斥锁；完整车队交通 **TBD**。
4. **电梯**：独立技能 `CallElevator` / `EnterElevator` / `ExitElevator`；失败则任务失败并告警。
5. **充电**：电量阈值触发 `DockCharge`；可配置最低执行电量。

## 7. 与他厂方案对比要点

| 维度 | 他厂（派特纳评估方案，参考） | 本系统 |
|------|------------------------------|--------|
| 产品形态 | 监测 + **吸尘/拖地清洁**一体 | **仅环境监测**；不做清洁 |
| 软件 | 车载安卓 APP + 服务器 MySQL + 看板 | **上位机自研**，FastAPI + Web，多客户端 |
| 调度 | 偏单机任务/定时 | **多机编排**、组合/集群任务 |
| 集成 | 偏固定仪器选型 | **适配层**多型号可替换 + Fake |
| 合规 | 未强调 Part 11 | **审计/电子签名可开关** |
| 跨层 | 材料未展开电梯 | **电梯联动**为明确诉求 |
| 远期 | 未强调臂 | **协作臂 + 深度相机**路线 |

他厂现场 WiFi 十条要求（协议、覆盖、延迟、信道、VLAN、漫游等）可作为**现场勘察检查单参考**，指标需本项目复测后写入验收协议，**不直接列为供应商承诺**。

## 8. 环境与部署

- **服务器**：Ubuntu LTS 优先；最低配置随并发与数据量评估（他厂提 i3/16G/500G 仅作小规模参考）。
- **运行**：`uv sync` + systemd 或 Docker Compose。
- **网络**：中控有线接入与机器人同逻辑网段/专用 VLAN；与办公网隔离建议。
- **时间同步**：NTP。
- **备份**：DB + 配置 + 报告文件；异地副本策略 TBD。

## 9. 开放问题与供应商协作点

### 9.1 开放问题

1. AMR 短名单与 API/电梯能力验证计划。
2. 仪表最终型号与通讯样例联调。
3. 风速高点采样机构（固定杆/升降/臂）。
4. 边端软件由谁开发（自研轻量代理 vs 全上云直连）。
5. 首个试点厂房与洁净等级。
6. 前端 React vs Vue。
7. 数据库与时序方案。
8. 制药客户是否 MVP 即开审计/签名。

### 9.2 供应商协作

| 对方 | 协作内容 |
|------|----------|
| AMR 厂 | 改装设计、API、充电桩、电梯二开、洁净材质 |
