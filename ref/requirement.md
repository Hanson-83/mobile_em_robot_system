# 背景
规划构建一套移动环境监测机器人系统，该系统由软硬件组成，用于无尘室/洁净室的自动环境监测与数据采集。
这套系统可应用于：
- 半导体行业：大规模集成电路/晶圆厂，液晶面板等
- 制药：GMP设施
- 生命科学：实验室
- 新能源：锂电池等
- 医疗：医院相关设施等
- 其他：有无尘/洁净环境要求的行业
# 需求
## 系统组成
该系统主要由移动机器人系统、上位机组成。
- 移动机器人系统包括：移动机器人本体、便携式粒子计数器、便携式浮游菌采集器、在线温湿度仪、在线风速仪、其他监测仪表与采样机构等。
- 上位机：主要有服务器和客户端组成，包括相应的软件。
移动机器人系统负责具体的现场工作，包括：导航到监测区域/点位，进行在线监测与采样等
上位机负责中央编排调度控制移动机器人系统执行相关任务，控制仪器采样和监测，将采集的数据持久化，并且可以以UI/看板形式可视化呈现，包括动态和静态的可视化，相当于是一个小中控/scada系统。
上位机和移动机器人系统通过无线通信，一个上位机节点可以编排调度控制多台移动机器人执行相关任务，采集相关数据，并且可以实时监控机器人的状态，包括：当前所在位置、状态等，上位机的UI/看板里可以载入地图，并且可视化动态呈现移动机器人的移动状态。
移动机器人主要基于标准的AMR进行改装，需要有SLAM建图功能、位置标定与管理、自动导航、自动避障等功能，上面安装有便携式粒子计数器、便携式浮游菌采集器、在线温湿度仪、在线风速仪、其他监测仪表与采样机构等。
## 选型、设计与开发
1. 需要选择合适的AMR厂家或轮式移动巡检机器人厂家，并且对方支持改装以在内部集成、便携式粒子计数器、便携式浮游菌采集器、在线温湿度仪、在线风速仪、其他监测仪表与采样机构等。
1.1. 初版以最小化配置为要求，需包括如下：
- 便携式粒子器及采样头
- 在线温湿度仪及采样头
- 在线风速
- 无线路由器：实现无线通信
- 电池及相关电源插座
- AMR的API
- 充电桩
- AMR本身控制系统功能扩展或二开：适配于电梯交互，进出电梯，实现跨越楼层的移动
- AMR需具备：SLAM建图、点位配置与管理、自动导航、自动避障、自动充电、电梯联动等功能
1.2. 后期需能扩展，包括如下：
- 便携式浮游菌采集器（包括模块和采集头）
- 其他涉及环境监测相关的在线或便携式仪表/仪器以及采样机构
1.3. 未来需考虑机械臂扩展，包括：
- 带末端工具的协作机械臂，优先以国产的为主。
- 机械臂末端需配置深度相机。
- 机械臂以6轴或7轴为主。
- 可能会将采样头安装到机械臂上，比如末端合适位置，然后在执行任务中，由机械臂移动到固定的静态位置进行采样/监测，或机械臂按固定的轨迹进行采样/监测。
2. 需要开发一套上位机软件系统，该上位机需具备一系列功能和特性。
2.1. 机器人控制
- 能下发订单，调度机器人执行相关任务，比如：执行去某个区域采样与监测。
- 能够编排机器人任务，比如一个任务是由一组原子技能组成的，然后一个组合任务是有一组任务组成的，比如：先去区域A执行采样，然后去区域B执行采样，然后等待某个时间点或某个事件触发，再去C执行。
- 能集群调度编排控制多个机器人进行各自单独的任务或集群任务。
- 机器人状态与位置实时监测，并可视化呈现。
- 地图可视化，包括：地图，机器人的位置和移动。
2.2. 数据采集与可视化
- 主要是悬浮粒子、温湿度、风速等
- 实时数据、动态趋势、历史数据、历史趋势可视化
- 监测与采样点位管理
- 极限设置与报警功能
- 数据缓存/断点续传功能
2.3. 报警与事件
- 实时的报警与事件消息
- 异常处理
- 历史记录
2.4. 批报告
- 每次完成任务后生成报告，包括单个任务、组合任务以及集群任务
2.5. 用户权限与安全访问管理
- 多用户
- 多用户组
- 权限可配置
- 安全策略配置
2.6. 审计追踪与电子签名
- 具备审计追踪功能（可开启关闭）
- 具备电子签名功能（可开启关闭）
2.7.备份与灾难恢复
- 可自动备份或手动备份
- 可灾难/备份恢复
2.8. 多型号设备/硬件/组件适配
- 可通过驱动网关/框架/适配器适配不同的粒子计数器、相关仪表\仪器、机器人系统
2.9. 多客户端架构
- 支持游览器、桌面端app、移动端app多种客户端类型
2.10. 对外API
- 需支持对外暴露API，可供三方系统调用与通信交互
